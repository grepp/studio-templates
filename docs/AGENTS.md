# AI Agent Development Guide

## 1. 목적

이 문서는 비개발자 또는 AI를 활용하여 생성된 코드를  
회사 운영 표준에 맞는 형태로 리팩토링하고,  
운영 가능한 서비스로 전환하기 위한 가이드이다.

AI는 본 문서를 기준으로 다음을 수행해야 한다:

- 코드 구조 정리
- 보안 기준 적용
- 실행 및 배포 환경 구성
- 필수 문서 생성

---

## 2. 기본 원칙

- 기능 추가보다 **운영 가능성 확보를 우선**한다
- 불완전한 코드는 보완하되, 추측이 필요한 경우 명시적으로 기록한다 (TODO)
- 민감정보는 제거하거나 dummy 값으로 대체한다
- 모든 설정은 코드가 아닌 **환경 변수 기반**으로 분리한다
- 운영 데이터 사용금지

---

## 3. 기술 표준

### 3.1 실행 환경
- 애플리케이션은 **Docker 기반으로 실행 가능해야 한다**
- `docker build` 및 `docker run`으로 실행 가능하도록 구성한다

### 3.2 운영 환경
- 운영 배포는 **Kubernetes (Helm)** 기준으로 구성한다
- 최소한 Helm chart 또는 values 예시를 생성한다

### 3.3 데이터베이스
- 기본 DB는 **PostgreSQL 16.x 기준**으로 구성한다
- DB 연결은 환경 변수 기반으로 처리한다

### 3.4 언어
- Python 또는 Ruby 기반을 권장한다
- 기타 언어 사용 시 실행 방법을 명확히 문서화한다

---

## 4. 보안 표준

### 4.1 금지사항
- 비밀번호, API Key, 토큰, 인증정보를 코드에 직접 포함하지 않는다
- DB 접속정보를 코드 또는 문서에 평문으로 저장하지 않는다

### 4.2 환경 변수
- 모든 민감정보는 환경 변수로 분리한다
- `.env.example` 파일을 생성하되 실제 값은 포함하지 않는다

### 4.3 인증 및 권한
다음 중 하나에 해당하면 인증 구조를 추가한다:

- 여러 사용자가 접근하는 경우
- 데이터 조회/수정 기능이 있는 경우

가능한 경우:
- 기본 인증 구조 (JWT, Session 등) 추가
- 관리자 / 일반 사용자 구분

### 4.4 로그 보안
- 로그에 다음 정보가 포함되지 않도록 한다:
  - 개인정보
  - 인증 토큰
  - 비밀번호

## 7. 외부 API / AI 사용 시

- 검증 또는 확인 단계 필요
